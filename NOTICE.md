# Notices

`rmtdos-utils` collects related tools built around the rmtdos remote DOS control
protocol.

The repository history starts from `l00nix/rmtdos-cga-web`, a fork of Dennis
Jenkins' original `rmtdos` project:

- Original project: https://github.com/dennisjenkins75/rmtdos
- CGA web fork: https://github.com/l00nix/rmtdos-cga-web

`rmtdos-file-commander` is imported as the file-manager utility for DOS hosts
running the matching `cgaweb.com` TSR:

- File commander project: https://github.com/l00nix/rmtdos-file-commander
